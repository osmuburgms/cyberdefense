\section{Script de entrenamiento del modelo LightGBM}
\label{app:entrenamiento}

El Código~\ref{lst:entrenamiento} presenta el script con el que se entrena el modelo de detección descrito en la Sección~\ref{sec:ia}. El script carga el conjunto de entrenamiento balanceado y el conjunto de prueba, codifica las 14 etiquetas, entrena el clasificador LightGBM con los hiperparámetros indicados, evalúa el modelo sobre la prueba y guarda el modelo y el codificador como artefactos.
